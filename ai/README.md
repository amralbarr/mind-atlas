# AI

What AI can do, and which software does it — kept as two linked sub-trees under one root so a tool (e.g. Blender) is never duplicated across every capability it supports.

- **[solutions/](solutions/)** — capabilities, organized by modality (text, image, video, audio, 3d-and-spatial, code, documents, multimodal, physical-and-robotics, structured-data). What AI can actually do.
- **[tools-platforms/](tools-platforms/)** — the software/products that implement those capabilities, including AI-assisted features of traditional platforms (AutoCAD, SolidWorks, Blender, ...) documented as features, not whole-product AI claims.

See [solutions/README.md](solutions/README.md) for the full capability tree and the note template, and [tools-platforms/README.md](tools-platforms/README.md) for the tool catalog and its template.

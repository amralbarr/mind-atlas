# FLUX (Black Forest Labs)

**Type:** Open weight (FLUX Kommunity License — free commercial use for individuals/businesses under $5M annual revenue) + Paid (API, metered per image)

## Category
Text-to-image and image-editing diffusion model family

## AI Capabilities
- Text-to-image generation across the FLUX.1/FLUX.2/FLUX 3 model family
- FLUX Kontext — image-conditioned editing: edit or restyle an existing image from a reference image plus a text instruction, rather than generating from scratch
- FLUX 3 Image Klein — a 5.6B parameter open-weight model light enough for consumer GPUs; API pricing starts around $0.009 per 1,000 images at the small-model tier
- Larger organizations (over the free-use revenue threshold) need a self-hosted license or pay-per-use API access

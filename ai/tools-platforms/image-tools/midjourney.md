# Midjourney

**Type:** Paid (subscription: $10/$30/$60/$120 per month for Basic/Standard/Pro/Mega, ~20% cheaper billed annually)

## Category
Text-to-image generation (hosted web app, no self-hosting)

## AI Capabilities
- High-aesthetic text-to-image generation, widely regarded as the strongest out-of-the-box visual style among mainstream generators
- Image variation/upscaling, Stealth Mode (private generations, Pro tier and up), short SD video generation from an image (Pro/Mega)
- Plans differ mainly by monthly "Fast" GPU-time allowance and whether unlimited slower "Relax" mode generation is included

## Related AI Solutions
- [Text-to-Image Generation](../../solutions/image/image-generation/text-to-image-generation.md)

## Notes
- No free tier or trial as of 2026; generation happens through Midjourney's own web app (Discord is no longer required).
- No public generation API — integrate it into a product only through unofficial/unsupported means, unlike [OpenAI's image API](openai-image-generation.md) or [Adobe Firefly](adobe-firefly.md).

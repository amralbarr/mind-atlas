# ComfyUI

**Type:** Open source (GPL-3.0)

## Category
Node-based local workflow engine/UI for diffusion models

## AI Capabilities
- Visual node-graph editor for wiring together any diffusion model ([Stable Diffusion](stable-diffusion.md), [FLUX](flux.md)), [ControlNet](controlnet.md), [IP-Adapter](ip-adapter.md), upscalers, and video models into a custom pipeline
- Runs fully locally (Windows/macOS/Linux/Docker); exposes every internal step of a generation instead of hiding it behind a simple prompt box
- New model/technique releases (e.g. FLUX Kontext) typically ship as a ComfyUI workflow first, sometimes exclusively

## Notes
- The dominant open-source Stable Diffusion/FLUX frontend as of 2026, with well over 100K GitHub stars and a new core release roughly every two weeks.
- Steeper learning curve than a simple web app — compare to [Krita AI Diffusion](krita-ai-diffusion.md) for an artist-friendly in-app alternative, or hosted products like [Midjourney](midjourney.md)/[Adobe Firefly](adobe-firefly.md) when no local setup is wanted.

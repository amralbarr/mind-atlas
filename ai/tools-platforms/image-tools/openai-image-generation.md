# OpenAI Image Generation (GPT Image)

**Type:** Paid (API: per-token or ~$0.01–$0.17 per image depending on quality/resolution; also built into ChatGPT)

## Category
Text-to-image generation and mask-based editing via API

- Text-to-image generation that leans on GPT's language understanding to follow long, multi-part, compositional prompts more reliably than pure diffusion models
- Mask-based image editing/inpainting through the same API
- API pricing: roughly $10 per million input tokens / $40 per million output tokens (standard), with batch pricing at $2.50/$20 per million
- `gpt-image-1` was deprecated October 23, 2026 — new integrations should target the current GPT Image model generation

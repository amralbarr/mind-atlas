# AI Tools & Platforms

A catalog of software, tools, and platforms — organized by what they work with. One tool can support multiple [solutions/](../solutions/) capabilities, so it's linked from each rather than duplicated.

Important distinction: a traditional software platform (AutoCAD, SolidWorks, Blender, Revit, ...) is **not itself an AI solution**. Document the platform here, and specifically note which of its features are AI-powered (what the AI does, what model/approach it uses if known) rather than treating the whole product as "AI."

- **[text-and-llm-tools/](text-and-llm-tools/)** — chat assistants, LLM providers/APIs, writing tools
- **[image-tools/](image-tools/)** — image generation/editing tools (Midjourney, DALL-E, Photoshop AI features, ...)
- **[video-tools/](video-tools/)** — video generation/editing tools (Runway, Sora, Premiere AI features, ...)
- **[audio-tools/](audio-tools/)** — TTS/STT/voice/music tools (ElevenLabs, Whisper, Suno, ...)
- **[3d-and-cad-software/](3d-and-cad-software/)** — AutoCAD, SolidWorks, Blender, Autodesk Revit, Autodesk Fusion, Rhino 3D, SketchUp, Unreal Engine, Unity — document only their AI-assisted features/integrations, not the whole product
- **[development-tools/](development-tools/)** — AI coding tools (Copilot, Cursor, Claude Code, ...)
- **[ai-platforms/](ai-platforms/)** — cross-capability platforms/model hubs (OpenAI, Anthropic, Hugging Face, ...)
- **[hr-and-recruiting-tools/](hr-and-recruiting-tools/)** — ATS platforms, resume parsing/screening, and AI interview (chat/voice/video) providers

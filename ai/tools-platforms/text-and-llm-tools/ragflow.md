# RAGFlow

**Type:** Open source (Apache 2.0) — by InfiniFlow

## Category
RAG engine with a built-in web UI, specialized in document understanding

## AI Capabilities
- Deep parsing of messy source documents: scanned PDFs, tables, complex layouts
- Chunking strategy tuned per document type rather than naive fixed-size splitting
- Citation-grounded answers out of the box

## Notes
- Best pick when source documents are heterogeneous/poorly structured rather than clean Markdown/HTML — that's its main differentiator from [Haystack](haystack.md)/[Verba](verba.md).

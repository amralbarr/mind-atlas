# LanguageTool

**Type:** Open source (LGPL-2.1) core, with paid Premium/Business/on-premise tiers

## Category
Grammar, style, and spell checker

## AI Capabilities
- Grammar, spelling, punctuation, and style checking across 25+ languages
- Rule-based + statistical/neural checks, with AI-assisted rephrasing suggestions on paid tiers
- Self-hostable via Docker for teams that want full data control

## Related AI Solutions
- [AI Writing Assistants & Content Generation](../../solutions/text/writing-and-content-generation/ai-writing-assistants.md)

## Notes
- The main self-hostable, open-source alternative to Grammarly — community Docker images exist, and an official installer is in the GitHub repo.
- Premium (cloud, non-self-hosted) is $69.99/year; the browser extension's advanced features became Premium-only in March 2026.

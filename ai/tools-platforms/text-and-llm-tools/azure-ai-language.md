# Azure AI Language

**Type:** Paid — $1.00/1,000 text records for sentiment (volume discounts to $0.75/1,000 past 500K); 5,000 free records/month

## Category
Managed NLP API (sentiment, entities, classification, summarization)

## AI Capabilities
- Sentiment analysis with opinion mining (aspect-based sentiment) billed inside the standard sentiment call at no extra charge
- Named entity recognition supporting 79+ languages generally available (~94 in preview)
- Key phrase extraction, language detection, extractive/abstractive summarization, and conversational language understanding, all sharing the same free monthly quota

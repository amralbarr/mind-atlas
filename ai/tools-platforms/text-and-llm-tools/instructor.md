# Instructor

**Type:** Open source (MIT)

## Category
Structured-output library for LLMs

## AI Capabilities
- Defines the target extraction schema as a Pydantic model (or equivalent in TypeScript/Ruby/PHP/Elixir) and uses it to constrain and validate an LLM's response
- Automatic retry/re-ask on validation failure
- Works across OpenAI, Anthropic, Gemini, and most other LLM providers

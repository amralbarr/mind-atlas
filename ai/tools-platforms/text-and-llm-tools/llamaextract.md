# LlamaExtract

**Type:** Paid — credit-based (1,000 credits = $1.25); free tier 10,000 credits/month; paid plans from $50/month

## Category
Managed schema-based document/text extraction service (part of LlamaCloud)

## AI Capabilities
- Define a schema (Pydantic or JSON Schema), point it at documents/text, get schema-validated structured output back
- Multiple accuracy/cost tiers per page: Cost-effective, Agentic, Agentic Plus, and Turbo, trading price for extraction accuracy and grounding quality
- Built on the same underlying framework as [LlamaIndex](../../../../engineering/concepts/ai/agents/llamaindex.md), as a managed cloud product

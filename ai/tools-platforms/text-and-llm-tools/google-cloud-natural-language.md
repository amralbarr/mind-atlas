# Google Cloud Natural Language

**Type:** Paid — usage-based pricing, free monthly quota

## Category
Managed NLP API (sentiment, entities, classification, syntax)

## AI Capabilities
- Sentiment analysis and entity-sentiment analysis (sentiment attributed to specific entities, v1 API)
- Entity analysis, content classification, and syntax analysis
- v2 of the API trades entity-sentiment and syntax analysis for a simpler surface plus content moderation — v1 is still required for entity-sentiment/syntax use cases

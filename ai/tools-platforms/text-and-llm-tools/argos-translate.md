# Argos Translate

**Type:** Open source (MIT)

## Category
Offline neural machine translation library

## AI Capabilities
- Python library for offline, on-device translation using downloadable per-language-pair neural models
- Powers [LibreTranslate](libretranslate.md)'s translation engine under the hood
- Lower resource footprint than LibreTranslate (no server/web-UI layer) — suited to embedding translation directly into an application

## Related AI Solutions
- [Machine Translation](../../solutions/text/translation/machine-translation.md)

## Notes
- Choose Argos Translate over LibreTranslate when you want a translation library to embed in your own app; choose LibreTranslate when you want a ready-made API server with a UI.

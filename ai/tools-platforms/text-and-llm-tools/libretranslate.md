# LibreTranslate

**Type:** Open source (AGPL-3.0)

## Category
Self-hosted machine translation API

## AI Capabilities
- REST API + web UI for machine translation, fully self-hostable and offline-capable
- Built on top of [Argos Translate](argos-translate.md)'s neural translation models
- No per-character fees, no external API calls once self-hosted

## Related AI Solutions
- [Machine Translation](../../solutions/text/translation/machine-translation.md)

## Notes
- Trades some translation quality/fluency versus DeepL/Google/Azure for full data privacy and zero marginal cost.
- ~16k GitHub stars as of 2026, the more widely adopted of the two Argos-based self-hosted translation projects.

# AWS Comprehend

**Type:** Paid — usage-based (per-character/per-unit pricing), AWS free tier available

## Category
Managed NLP API (sentiment, entities, classification)

## AI Capabilities
- Sentiment analysis (overall and targeted/per-entity) with confidence scores
- Named entity recognition, key phrase extraction, language detection, PII/sensitive-information detection
- Custom entity recognition and custom document classification trainable on your own labeled data

- [Sentiment Analysis, Entity Extraction & Text Classification](../../solutions/text/text-analysis/sentiment-and-entity-analysis.md)

## Notes
- As of April 30, 2026, Topic Modeling, Event Detection, and Prompt Safety Classification are no longer available to new customers — core sentiment/entity/classification features are unaffected.
- Supports English, Spanish, French, German, Italian, Portuguese, Japanese, Korean, Chinese, Arabic, and Hindi for its main analysis APIs.

# Haystack

**Type:** Open source (Apache 2.0) — by deepset

## Category
RAG / LLM orchestration framework

## AI Capabilities
- Pipelines for retrieval, generation, and agents
- Technology-agnostic: swap the vector store or LLM without rewriting the application
- Built-in evaluation tooling for RAG pipeline quality

# spaCy

**Type:** Open source (MIT)

## Category
Production NLP library

## AI Capabilities
- Named entity recognition, part-of-speech tagging, dependency parsing, and text classification pipelines
- Pretrained statistical and transformer-backed models for 70+ languages
- Designed for production use (fast, memory-efficient) rather than research experimentation

## Related AI Solutions
- [Sentiment Analysis, Entity Extraction & Text Classification](../../solutions/text/text-analysis/sentiment-and-entity-analysis.md)

## Notes
- The standard self-hosted choice when you need entity extraction/classification without per-call API costs or sending data to a third party.
- Does not include sentiment analysis out of the box — typically paired with a classification model/pipeline trained for that specific task.

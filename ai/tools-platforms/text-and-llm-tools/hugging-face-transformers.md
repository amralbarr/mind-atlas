# Hugging Face Transformers

**Type:** Open source (Apache 2.0)

## Category
Machine learning model library (NLP/summarization/translation/classification models)

## AI Capabilities
- Ready-to-use pipelines for summarization, translation, classification, NER, and more via pretrained models
- Pretrained summarization models such as `facebook/bart-large-cnn` (BART) and PEGASUS, usable with a few lines of code
- Self-hostable, fine-tunable on your own data; no per-call API cost when run locally

## Related AI Solutions
- [Document & Meeting Summarization](../../solutions/text/summarization/document-and-meeting-summarization.md)

## Notes
- A library you assemble into a pipeline, not a finished product — compare to [Otter.ai](otter-ai.md)/[Fireflies.ai](fireflies-ai.md) for a ready-made meeting-summarization app.
- The Hugging Face Hub (hosting pretrained models/datasets) has its own separate paid tiers for private hosting and inference endpoints; the `transformers` library itself is free and open source.

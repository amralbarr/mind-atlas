# Module: Math for Machine Learning

**Category:** Data & ML · **Typical duration:** 2 weeks (15–20 hrs/week) · **Prerequisite modules:** [Programming Fundamentals](../foundations/programming-fundamentals.md)

## Goal

Build enough intuition in linear algebra, calculus, and probability to understand how models learn — not to prove theorems, but to read a paper's math without flinching.

## Core topics

- [ ] Linear algebra: vectors, dot product, cosine similarity, matrices, matrix multiplication
- [ ] Calculus: derivatives, the chain rule, gradients
- [ ] Probability and statistics: distributions, Bayes' rule, expectation/variance, softmax, cross-entropy
- [ ] Vectorized computation with your language's numerical array library and a tabular-data library

## Resources

- A well-known visual series on linear algebra and calculus intuition (free)
- A free "math for machine learning" course covering probability/statistics for the ML context

## Milestone deliverable

A short notebook implementing cosine similarity, softmax, and cross-entropy from scratch (no library shortcuts), with a written explanation of each.

# Module: Classical Machine Learning

**Category:** Data & ML · **Typical duration:** 3 weeks (15–20 hrs/week) · **Prerequisite modules:** [Math for ML](math-for-ml.md)

## Goal

Train, evaluate, and explain a traditional ML model end to end — the baseline every deep-learning pitch should be compared against.

## Core topics

- [ ] Supervised learning: linear/logistic regression, trees, random forests, gradient boosting
- [ ] Unsupervised learning: k-means, PCA, clustering
- [ ] Evaluation: train/val/test splits, cross-validation, precision/recall/F1, ROC-AUC, overfitting
- [ ] Feature engineering and ML pipelines
- [ ] Reading a model's feature importances / basic explainability

## Resources

- A structured, widely-used "machine learning specialization"-style free/audit-able course
- Your ecosystem's standard ML library's official user guide
- One tabular dataset competition relevant to your target domain

## Milestone deliverable

A classification or regression model with a full pipeline (preprocessing → training → evaluation) and a short written report of the metrics and what you'd try next.

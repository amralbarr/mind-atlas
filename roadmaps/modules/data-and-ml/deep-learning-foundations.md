# Module: Deep Learning Foundations

**Category:** Data & ML · **Typical duration:** 3 weeks (15–20 hrs/week) · **Prerequisite modules:** [Classical Machine Learning](classical-machine-learning.md)

## Goal

Understand how a neural network actually learns, and train one from scratch at least once, so later [LLM](../../../engineering/concepts/ai/generation/llm.md) concepts (attention, transformers) aren't a black box.

## Core topics

- [ ] Neural networks, backpropagation, activation functions, optimizers (SGD, Adam), regularization/dropout
- [ ] A deep learning framework: tensors, autograd, training loops, GPU basics
- [ ] CNNs and RNNs at a conceptual level — enough to explain why transformers replaced RNNs for sequence tasks
- [ ] Reading a loss curve: underfitting vs overfitting vs a learning-rate problem

## Resources

- A "zero to hero" style video series that has you build a tiny neural network/autograd engine by hand
- Your chosen framework's official quickstart tutorial
- A free, widely-used deep learning reference book

## Milestone deliverable

A small neural network trained from scratch (not a pretrained model) on a simple dataset, with the training loop written by hand and a short write-up of the loss curve.

# Module: Data Analysis & Experimentation

**Category:** Data & ML · **Typical duration:** 3 weeks (15–20 hrs/week) · **Prerequisite modules:** [Math for ML](math-for-ml.md), [Databases & Caching](../backend/databases-and-caching.md) (for the [SQL](../../../engineering/concepts/databases/relational/sql.md) half)

## Goal

Turn a raw dataset into a decision: explore it honestly, test a hypothesis rigorously, and design an experiment someone can actually trust the result of.

## Core topics

- [ ] Exploratory data analysis: distributions, outliers, missing-data patterns, correlation vs causation traps
- [ ] Hypothesis testing: choosing the right test, p-values and their common misinterpretation, confidence intervals
- [ ] A/B test design: sample size and power calculation, randomization, avoiding peeking/multiple-comparisons problems
- [ ] Causal-inference basics: confounders, Simpson's paradox, why a correlation isn't a recommendation
- [ ] Data visualization for analysis (exploratory) vs for an audience (explanatory) — these are different skills
- [ ] Writing a findings report: the headline first, the caveats stated plainly, the recommendation explicit
- [ ] Advanced SQL for analytics: window functions, cohort queries, funnel analysis

## Milestone deliverable

An end-to-end analysis on a real or realistic dataset: exploratory analysis, one properly designed and analyzed hypothesis test or A/B test, and a short written report aimed at a non-technical stakeholder with a clear recommendation.

# Module: Programming Fundamentals

**Category:** Foundations · **Typical duration:** 3–4 weeks (15–20 hrs/week) · **Prerequisite modules:** none

## Goal

Write clean, idiomatic code in your primary language without looking up the basics — syntax, data structures, control flow, functions, and enough intermediate style ([OOP](../../../engineering/concepts/programming/fundamentals/oop.md), comprehensions, decorators, type hints) to read other people's production code comfortably.

## Core topics

- [ ] Syntax, variables, core data types, operators, casting
- [ ] Core data structures (arrays/lists, maps/dicts, sets, tuples) and their standard methods
- [ ] Control flow: conditionals, pattern matching, loops
- [ ] Functions: parameters, variadic args, [closures](../../../engineering/concepts/programming/javascript/closures.md)/lambdas, scope
- [ ] Modules/packages, dependency management, virtual environments (for interpreted languages)
- [ ] Error handling: try/catch, custom exceptions
- [ ] File [I/O](../../../engineering/concepts/programming/fundamentals/io.md): text, CSV, [JSON](../../../engineering/concepts/programming/fundamentals/json.md)
- [ ] OOP: classes, inheritance, interfaces/protocols, composition
- [ ] Comprehensions, generators, and iterators (if the language supports them)
- [ ] Type hints / static typing basics
- [ ] Style and linting conventions for the language
- [ ] Unit testing basics

## Resources

- The language's own official tutorial/docs — always the first stop
- A structured free course for the first pass, then a deeper book or the official language guide for intermediate topics
- 20–30 easy coding-challenge problems on arrays, strings, and dicts

## Milestone deliverable

A small CLI tool that reads a folder of structured files (CSV/JSON), transforms or cleans the data, and writes a summary report. Use classes, type hints, logging (not print statements), and a test suite. Push it to a public repo with a README.

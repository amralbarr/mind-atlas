# Module: Version Control & Command Line

**Category:** Foundations · **Typical duration:** ~1 week (15–20 hrs/week) · **Prerequisite modules:** none (pairs well with [Programming Fundamentals](programming-fundamentals.md))

## Goal

Work comfortably in a terminal and collaborate on code through Git without fear — branch, review, resolve conflicts, and understand what a CI pipeline will do with your commits.

## Core topics

- [ ] Shell basics: navigating the filesystem, processes, permissions, environment variables, ssh
- [ ] Git: init/clone, staging, commits, branching, merging vs rebasing, resolving conflicts
- [ ] Pull requests / merge requests: review etiquette, squash vs merge commits
- [ ] `.gitignore`, git [hooks](../../../engineering/concepts/frontend/hooks.md), conventional commit messages
- [ ] [HTTP](../../../engineering/concepts/networking/http.md) fundamentals: methods, status codes, headers, [JSON](../../../engineering/concepts/programming/fundamentals/json.md) — needed to read any API documentation later

## Resources

- *Pro Git* (free online book), chapters 1–3
- A "missing semester"-style free course covering shell and git in depth

## Milestone deliverable

Fork a small open-source repo, make a real improvement (docs fix, small feature, or failing-test fix), and open a pull request following the project's own contribution guidelines.

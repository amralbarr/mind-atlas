# Module: Domain Specialization (placeholder)

**Category:** Career · **Typical duration:** varies, usually folded into weekly study time throughout · **Prerequisite modules:** none — run in parallel with any technical module

## Goal

Every job sits inside a specific industry with its own vocabulary, regulation, and typical use cases. This module is intentionally a placeholder: fill it in per-roadmap with the target industry's real content, since industry knowledge doesn't generalize the way a technical module does.

## How to fill this in for a real roadmap

- [ ] List the domain's core business vocabulary and workflows (e.g. for fintech: accounts, transactions, underwriting; for healthtech: patient records, care pathways, consent)
- [ ] List the domain's typical AI/software use cases, so your portfolio project targets a realistic one
- [ ] List the domain's relevant regulation/compliance frameworks, if any, and what technical control maps to each requirement
- [ ] Note any domain-specific data-handling quirks (language/locale, specialized terminology, regulated data categories) that change how earlier modules — especially [Retrieval-Augmented Generation](../ai-llm/retrieval-augmented-generation.md) and [Security Fundamentals](../platform/security-fundamentals.md) — should be built

## Milestone deliverable

A one-page mapping from each domain requirement/regulation to a concrete feature of your portfolio capstone (e.g. "consent tracking" maps to an audit log plus opt-out flag, "data residency" maps to a self-hosted deployment).

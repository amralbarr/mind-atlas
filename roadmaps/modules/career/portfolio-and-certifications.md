# Module: Portfolio & Certifications

**Category:** Career · **Typical duration:** ongoing, finalized in the last 1–2 weeks · **Prerequisite modules:** every technical module the roadmap includes

## Goal

Turn a pile of milestone projects into one coherent, presentable portfolio, and pick certifications that actually move the needle for this specific role rather than collecting badges.

## Core topics

- [ ] Chain milestones into one flagship project per roadmap, not a pile of disconnected toy projects
- [ ] One repo with an architecture diagram in the README
- [ ] A results table with real numbers (accuracy/quality metric, latency, cost) — not just "it works"
- [ ] A short demo (video or live walkthrough) and a write-up per milestone
- [ ] Use only public or synthetic data in anything shared publicly — never real customer/user data
- [ ] Certification selection: match certs to what the job posting actually names, verify on the vendor's site that each cert is still current (vendors retire and rename certs), and skip any cert that's pure vendor badge-collecting with no real skill overlap

## Resources

- The target cloud/vendor's own current certification catalog — always check for retirements/renames before planning around a named cert

## Milestone deliverable

A single public repository presenting the roadmap's flagship project, plus a short table mapping each portfolio piece to the job requirement it proves.

# Example: Job Profile — MLOps / ML Platform Engineer

A filled-in example of [../templates/job-profile-template.md](../../templates/job-profile-template.md) for a generic, widely-posted archetype rather than one real posting.

## Role

- **Title:** MLOps Engineer / ML Platform Engineer
- **Seniority:** Mid / Senior
- **Domain/industry context:** generic — any organization running more than a handful of models in production, where "someone owns the platform" has become a real need

## Required skill categories

- [ ] Strong backend engineering and systems fundamentals
- [ ] Containers, orchestration, and [CI/CD](../../../engineering/concepts/devops/ci-cd.md)
- [ ] Cloud [infrastructure as code](../../../engineering/concepts/cloud/iac/infrastructure-as-code.md)
- [ ] Model serving, registries, and rollout strategy
- [ ] Model and data-pipeline monitoring/observability
- [ ] Working knowledge of ML concepts (enough to support, not necessarily train, models)
- [ ] Security fundamentals for a multi-tenant or regulated platform

## Nice-to-have skills

- [ ] Distributed data/compute scheduling for training workloads
- [ ] GPU infrastructure experience
- [ ] Cost optimization for ML infrastructure at scale

## Soft skills / seniority signals

- Designs a platform other engineers self-serve against, rather than hand-holding every deployment
- Writes a runbook/postmortem culture for ML-specific incidents (a bad model rollout is still an incident)

## Certifications mentioned

- A cloud provider's DevOps/infrastructure certification, and sometimes a container-orchestration-specific one
- Re-verify against the vendor's current catalog before planning around it

## Notes

This archetype is closer to a platform/infrastructure engineer than a data scientist — it needs deep [MLOps & Cloud AI Platforms](../../modules/platform/mlops-and-cloud-ai-platforms.md) and [ML Monitoring & Observability](../../modules/platform/ml-monitoring-and-observability.md) coverage, but only enough [Classical Machine Learning](../../modules/data-and-ml/classical-machine-learning.md) to speak the data scientists' language, not to design models.

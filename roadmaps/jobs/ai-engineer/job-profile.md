# Example: Job Profile — Senior AI Engineer / Agentic AI Architect

A filled-in example of [../templates/job-profile-template.md](../../templates/job-profile-template.md), genericized from a real GenAI engineering job posting in financial services. No company name, posting URL, or candidate-fit notes — see the [privacy note](../../README.md#privacy-note) in the system README for why.

## Role

- **Title:** Senior AI Engineer / Agentic AI Architect
- **Seniority:** Senior / Architect
- **Domain/industry context:** regulated financial services — raises the bar on data residency, auditability, and on-prem/self-hosted deployment options

## Required skill categories

- [ ] Expert-level programming (Python)
- [ ] Production-ready APIs and microservices
- [ ] Machine learning and deep learning fundamentals
- [ ] [NLP](../../../engineering/concepts/ai/nlp.md), transformers, [embeddings](../../../engineering/concepts/ai/ingestion/embeddings.md)
- [ ] [Prompt engineering](../../../engineering/concepts/ai/generation/prompt-engineering.md) and [LLM](../../../engineering/concepts/ai/generation/llm.md) API integration
- [ ] Enterprise [RAG](../../../engineering/concepts/ai/rag/rag.md) over structured and unstructured data
- [ ] Multi-agent / agentic AI systems with human-in-the-loop approval
- [ ] [LLM evaluation](../../../engineering/concepts/ai/evaluation/llm-evaluation.md), guardrails, and observability
- [ ] Open-source LLM deployment and inference optimization
- [ ] MLOps and cloud AI platforms
- [ ] Understanding of relevant data-protection and AI-governance regulation
- [ ] Technology research and evidence-based evaluation — distinguishes a "builds what's asked" engineer from an "evaluates and recommends new technology" one, especially at Architect level

## Nice-to-have skills

- [ ] Knowledge-graph-based retrieval (GraphRAG)
- [ ] Multilingual / low-resource-language NLP support
- [ ] Text-to-[SQL](../../../engineering/concepts/databases/relational/sql.md) over a production database

## Soft skills / seniority signals

- Leads or mentors a team
- Owns architecture decisions and writes design docs
- Explains technical tradeoffs to non-technical stakeholders

## Certifications mentioned

- A generative-AI/LLM vendor certification (associate and professional level)
- One cloud provider's AI-engineering certification, matched to whichever cloud the employer uses
- Note: posting-listed certs should always be re-checked against the vendor's current catalog — AI certifications get renamed/retired frequently

## Notes

Regulated-industry context means the [Security Fundamentals](../../modules/platform/security-fundamentals.md) and [Domain Specialization](../../modules/career/domain-specialization.md) modules should weight compliance, audit-logging, and data-residency content more heavily than a generic consumer-app roadmap would.

A candidate who already has hands-on RAG/agent/self-hosted-LLM experience doesn't need to re-learn how to build these systems — the real gap at this seniority is [AI Research & Technology Benchmarking](../../modules/career/ai-research-and-benchmarking.md): proving a technology choice with evidence (a benchmark, a comparison, a documented recommendation) rather than asserting it from experience alone.

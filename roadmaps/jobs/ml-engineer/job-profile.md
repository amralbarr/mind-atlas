# Example: Job Profile — Machine Learning Engineer

A filled-in example of [../templates/job-profile-template.md](../../templates/job-profile-template.md) for a generic, widely-posted archetype rather than one real posting.

## Role

- **Title:** Machine Learning Engineer
- **Seniority:** Mid / Senior
- **Domain/industry context:** generic product company with a model-driven feature (recommendations, fraud/risk scoring, ranking, forecasting) — the specific use case changes the domain-specialization content, not the core module path

## Required skill categories

- [ ] Strong programming fundamentals (Python)
- [ ] Classical ML and deep learning fundamentals
- [ ] Production-ready APIs and services
- [ ] Databases, feature pipelines, and caching
- [ ] Model serving, versioning, and rollout strategy
- [ ] [CI/CD](../../../engineering/concepts/devops/ci-cd.md) and containerization for ML systems
- [ ] MLOps: experiment tracking, model registry, cloud ML platforms
- [ ] Model monitoring and drift detection
- [ ] [System design](../../../engineering/concepts/backend/architecture/system-design.md) for data-intensive systems

## Nice-to-have skills

- [ ] Distributed data processing for large training sets
- [ ] Deep learning specialization (vision or language) relevant to the product
- [ ] [A/B testing](../../../marketing/concepts/analytics/ab-testing.md) literacy to evaluate a shipped model's real impact

## Soft skills / seniority signals

- Works closely with data scientists/analysts to productionize a research model
- Can defend a model's architecture and rollout plan in a design review
- Communicates model limitations and risk honestly to product stakeholders

## Certifications mentioned

- A major cloud provider's ML engineering certification, matched to the employer's actual cloud
- Note: re-verify any named certification against the vendor's current catalog before planning around it

## Notes

Unlike a pure research role, this archetype is graded on production reliability as much as model quality — weight [ML Model Serving & Production Systems](../../modules/data-and-ml/ml-model-serving-and-production-systems.md) and [ML Monitoring & Observability](../../modules/platform/ml-monitoring-and-observability.md) heavily.

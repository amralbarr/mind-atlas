# Example: Computer Vision Engineer Roadmap, Zero to Hero

A worked example of the [roadmap system](../../README.md), assembled from [modules/](../../modules/) for the profile in [job-profile-computer-vision-engineer.md](job-profile.md). Swap the capstone's use case (retail analytics, industrial inspection, security, robotics) for whatever your own target domain needs.

## How to use this roadmap

- Total: ~30 weeks at 15–20 hours/week.
- **Fast-track rule:** try each phase's milestone first; skip ahead if you can already build it unaided.
- **Build, don't just watch:** every milestone extends the last into one deployed vision system.
- **Weekly rhythm:** roughly 65% building, 25% studying, 10% writing notes — this field rewards hands-on dataset/model iteration more than most.

## Phase 0 — [Programming Fundamentals](../../modules/foundations/programming-fundamentals.md) (weeks 1–3)

Goal: write clean code without looking up the basics.

## Phase 1 — [Version Control & CLI](../../modules/foundations/version-control-and-cli.md) + [APIs & Backend Services](../../modules/backend/apis-and-services.md) (weeks 4–7)

Goal: a real service skeleton to put the vision pipeline behind later.

## Phase 2 — [Math for ML](../../modules/data-and-ml/math-for-ml.md) → [Classical Machine Learning](../../modules/data-and-ml/classical-machine-learning.md) → [Deep Learning Foundations](../../modules/data-and-ml/deep-learning-foundations.md) (weeks 8–15)

Goal: understand how the models you'll fine-tune actually learn.

## Phase 3 — [Computer Vision Fundamentals](../../modules/computer-vision/computer-vision-fundamentals.md) (weeks 16–20)

Goal: the core of the role. Milestone: a real-time detection/tracking pipeline on a custom or public dataset, with an evaluation report and a demo video.

## Phase 4 — [Containers & CI/CD](../../modules/backend/containers-and-ci-cd.md) + [MLOps & Cloud AI Platforms](../../modules/platform/mlops-and-cloud-ai-platforms.md) (weeks 21–24)

Goal: get the vision pipeline from a script into a deployable, versioned service.

## Phase 5 — [Security Fundamentals](../../modules/platform/security-fundamentals.md) (week 25)

Goal: table-stakes review — vision systems often process sensitive footage, so this isn't optional.

## Phase 6 — [Domain Specialization](../../modules/career/domain-specialization.md) (weeks 26–27)

Goal: fill in the real use case's hardware budget, privacy rules, and accuracy bar.

## Phase 7 — [Soft Skills & Interview Prep](../../modules/career/soft-skills-and-interview-prep.md) (weeks 28–30)

Goal: interview-ready for CV [system design](../../../engineering/concepts/backend/architecture/system-design.md), coding, and behavioral rounds.

## Portfolio

| Project | Built in | Requirement it proves |
| --- | --- | --- |
| Data-cleaning CLI | Phase 0 | Programming fundamentals |
| Authenticated API skeleton | Phase 1 | Production-ready backend |
| Classical ML pipeline + from-scratch neural net | Phase 2 | ML/DL fundamentals |
| Real-time detection/tracking pipeline | Phase 3 | Core computer vision skill |
| Deployed, versioned vision service | Phase 4 | Production deployment |
| Domain-specific hardware/privacy mapping doc | Phase 6 | Domain fluency |

**Presenting it:** one repo, a demo video, an evaluation table (mAP, FPS on your actual hardware, model size). Use only public or synthetic footage/images.

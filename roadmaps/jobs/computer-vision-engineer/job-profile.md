# Example: Job Profile — Computer Vision Engineer

A filled-in example of [../templates/job-profile-template.md](../../templates/job-profile-template.md) for a generic, widely-posted archetype rather than one real posting.

## Role

- **Title:** Computer Vision Engineer
- **Seniority:** Mid / Senior
- **Domain/industry context:** generic — the real variants (retail analytics, industrial inspection, security/surveillance, autonomous systems, medical imaging) change the domain-specialization content and sometimes the latency/accuracy budget, not the core module path

## Required skill categories

- [ ] Strong programming fundamentals (Python, often C++ for real-time constraints)
- [ ] Deep learning fundamentals
- [ ] Computer vision: detection, segmentation, tracking, classical image processing
- [ ] Model training and [fine-tuning](../../../engineering/concepts/ai/infrastructure/fine-tuning.md) on custom datasets
- [ ] Real-time/edge deployment and inference optimization
- [ ] Production API/service integration for a vision pipeline

## Nice-to-have skills

- [ ] Embedded/edge hardware experience (GPU-constrained devices, camera integration)
- [ ] Multimodal vision-language models
- [ ] 3D vision / [sensor fusion](../../../engineering/concepts/robotics/sensor-fusion.md), if the role touches robotics

## Soft skills / seniority signals

- Can justify a model-architecture choice against a stated latency/accuracy/hardware budget
- Communicates dataset/annotation quality issues before they become a training-time surprise

## Certifications mentioned

- A deep learning framework or edge-AI hardware vendor's certification, if the employer's stack is vendor-specific
- Re-verify against the vendor's current catalog before planning around it

## Notes

Latency and hardware constraints dominate this role more than almost any other AI archetype — weight the deployment half of [Computer Vision Fundamentals](../../modules/computer-vision/computer-vision-fundamentals.md) and the production modules heavily, not just model accuracy.

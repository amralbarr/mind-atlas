# Example: Job Profile — Data Scientist

A filled-in example of [../templates/job-profile-template.md](../../templates/job-profile-template.md) for a generic, widely-posted archetype rather than one real posting.

## Role

- **Title:** Data Scientist
- **Seniority:** Mid
- **Domain/industry context:** generic product/analytics organization — swap in a specific industry (retail, fintech, healthtech) only if it changes the regulatory or data-sensitivity picture

## Required skill categories

- [ ] Strong programming fundamentals (Python) and [SQL](../../../engineering/concepts/databases/relational/sql.md)
- [ ] Statistics and experimentation (hypothesis testing, A/B tests)
- [ ] Classical machine learning
- [ ] Data analysis, visualization, and stakeholder-facing reporting
- [ ] Working with a data warehouse / relational database at scale

## Nice-to-have skills

- [ ] Deep learning exposure, if the role touches unstructured data (text, images)
- [ ] Causal inference for non-experimental data
- [ ] Dashboarding/BI tooling

## Soft skills / seniority signals

- Translates an ambiguous business question into a testable hypothesis
- Presents a finding's caveats honestly rather than overselling significance
- Partners with engineering to get a finding into production, without necessarily owning that deployment

## Certifications mentioned

- A data-analytics or statistics certification is sometimes listed but rarely load-bearing for this role — a strong portfolio of real analyses outweighs it

## Notes

This archetype is graded on analytical rigor and communication more than on shipping production code — [Data Analysis & Experimentation](../../modules/data-and-ml/data-analysis-and-experimentation.md) is the core module, not [APIs & Backend Services](../../modules/backend/apis-and-services.md) or deployment-heavy modules.
